# Backend (Express)

Minimal Express backend for the project.

Commands:

```bash
cd backend
npm init -y      # if package.json not present
npm install      # install dependencies
npm run dev      # start with nodemon (if installed)
npm start        # start normally
```

Endpoints:
- `GET /health`
- `GET /products`
- `POST /products`
- `GET /orders`
- `POST /orders`
